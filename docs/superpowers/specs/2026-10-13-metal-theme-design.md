# Тема «Шлифованный металл · Кость» и новый экран будильника: дизайн

Дата: 2026-10-13. Ветка: `feature/metal-theme`.

## Источник

Проект claude.ai/design «Trianon OCPP mobile project» (`8b66c04f-ed51-4a16-adf6-d21e46db37ec`):
- `DESIGN.md` / `DESIGN.json` v1.3.0 — тема по умолчанию «Шлифованный металл · холст „Кость“»;
- `Canvas-4.dc.html`, Turn 2 (2a экран, 2b шторка времени, 2c календарь) и его источник `Будильник.dc.html`.

Из Trianon берётся только эта тема; энергетический зелёный, карта, пины и тёмная тема Trianon в Chrono не переносятся.

## Цель

1. Всё приложение переходит с тёмной темы «Ночное небо» на светлую «Шлифованный металл · Кость».
2. Экран создания и изменения будильника — как в макете: плашка с временем, группы строк, шторки выбора.
3. В репозитории появляются собственные `DESIGN.md` и `DESIGN.json` Chrono — источник правды для токенов и компонентов.

Решения пользователя: тема на всё приложение (включая экран сигнала); «Повтор» и «Звук» — шторки, «Название» — поле в строке; экраны без макета строятся по дизайн-системе и утверждаются скриншотами; шторки, барабан и календарь — свои компоненты на MAUI без новых библиотек; логика расписания покрывается unit-тестами.

Статус-бар и панель навигации светлые (`#F5F2EC`/прозрачные) с тёмными иконками на всех экранах, включая экран сигнала поверх блокировки.

### 1.5 Документы

## 2. Экран будильника (`AlarmEditPage`)

Один экран для нового и существующего будильника. Сверху вниз:

1. **Шапка**: назад + «Новый будильник» / «Изменить будильник». При несохранённых правках «Назад» (кнопка, системный жест) спрашивает «Не сохранять изменения?» (системный диалог: «Отмена» / «Не сохранять»).
2. **Плашка**: `Metal` с кромкой `GoldEdge`, радиус 20, отступы 20/20/18.
   - eyebrow `Gold`: «СРАБОТАЕТ В СУББОТУ, 17 ОКТЯБРЯ»; для «Ближайшее» — «СРАБОТАЕТ СЕГОДНЯ, СБ 17 ОКТЯБРЯ» / «СРАБОТАЕТ ЗАВТРА, …»; для повторов — ближайшее срабатывание по `Alarm.NextAfter`.
   - время `plateTime` `OnMetal` слева, справа «через 20 ч 10 мин» (13/600, `OnMetal` 70 %) или «время уже прошло». Обновляется раз в 30 с, пока экран открыт.
3. **Группа 1**: «Время» (`15:56`), «Дата» (`17.10.2026` / «Ближайшее»; для «Каждый год» — «17 октября»; для «Каждый день» и «По дням недели» строка скрыта), «Повтор» («Однократно» / «Каждый день» / «Пн, Ср, Пт» / «Каждый год»).
4. **Группа 2**: «Название» — `Entry` прямо в строке, выравнивание вправо, плейсхолдер «Будильник», до 60 символов; «Звук» — имя мелодии или «Без звука»; «Вибрация» — тумблер.
5. **Подпись** `footnote`: «Изменения применяются по кнопке «Сохранить»».
6. **Ошибка** (если «Сохранить» отклонён): строка `GoldInk` над кнопками.
7. **Низ**, отступы 14/20/34: «Удалить» — квадрат 54, accent, иконка корзины (только у существующего); «Сохранить» — primary на остальную ширину, крайняя справа.

Новый будильник по умолчанию: время = сейчас + 1 ч (минуты как есть), дата «Ближайшее», однократно, «Колокол», вибрация вкл.

Корневой layout страницы — `SafeAreaEdges="Container, Container, Container, All"` (поле «Название» + клавиатура), режим окна `Resize` уже включён.

## 3. Шторки

### 3.1 Общая оболочка (`Controls/BottomSheet`)

- Слой поверх страницы: `Scrim` на весь экран (нажатие = «Отмена») и панель снизу: `Surface`, радиус 28 сверху, тень `0 −10 40 rgba(0,0,0,.25)`, отступы 10/22/34, ручка 44×5 `Hairline`.
- Заголовок `sheetTitle` слева, подсказка 13/600 `TextMuted` справа.
- Слот содержимого; внизу ряд кнопок: secondary «Отмена» и primary «Окей» (крайняя справа, шире).
- Системная «Назад» при открытой шторке закрывает шторку, а не страницу.
- Без анимаций появления (как в DESIGN.md: состояние коммитится напрямую).
- Правки внутри шторки — черновик в view model; переносятся в будильник только по «Окей».

### 3.2 Время (`TimeWheelSheet`)

- Подсказка справа — «через …» для черновика.
- Два барабана по 110 pt шириной, высота 224, строка 56; между ними «:» 32/800. Полоса выбора — `Surface2` с обводкой `Hairline`, радиус 16, по центру; сверху и снизу белое затухание 84 pt.
- Барабан — `CollectionView` (часы 0–23, минуты 0–59), `SnapPointsType=MandatorySingle`, `SnapPointsAlignment=Center`, пустые отступы сверху и снизу по 84 pt. Выбранное значение = `round(смещение / 56)`; выбранное число 40/800 `Text`, остальные 26/700 `Hairline`. Нажатие на число прокручивает к нему.
- Чипы 06:30 / 07:00 / 08:00 / «Сейчас».
- «Отмена» / «Окей».

### 3.3 Дата (`CalendarSheet`)

- Подсказка справа — «сб, 17 октября» или «Ближайшее подходящее».
- Навигация: кнопки ‹ › 42×42 (`Surface2`, обводка), по центру «Октябрь 2026» 16/700.
- Сетка 7 колонок, неделя с понедельника; заголовки дней — eyebrow, Сб и Вс — `GoldInk`.
- Ячейка 44 pt, кружок 40: прошедший день — `Hairline`, не нажимается; сегодня — кольцо 1.5 `Gold`, 800; выбранный — `Metal`, текст `OnMetal`, 800; выходные — `GoldInk`; остальные — `Text` 600. Для «Каждый год» прошедшие дни доступны (год не важен).
- Кнопки: accent «Очистить» (черновик → «Ближайшее»), secondary «Сегодня», primary «Окей».

### 3.4 Повтор (`RepeatSheet`)

- Четыре строки-варианта с отметкой ✓ у выбранного: «Однократно», «Каждый день», «По дням недели», «Каждый год».
- При «По дням недели» под ним ряд чипов Пн…Вс (неделя с понедельника), можно выбрать несколько; ни одного — «каждый день» (как `WeekDays.None` в модели).
- «Отмена» / «Окей».

### 3.5 Звук (`SoundSheet`)

- Строки: «Без звука», затем мелодии из `Sounds.All` в порядке модели; ✓ у выбранной.
- Нажатие на мелодию выбирает её и проигрывает один раз; «Без звука» останавливает прослушивание.
- «Отмена» / «Окей» останавливают прослушивание; уход со страницы — тоже.
- «Без звука» = `SoundEnabled = false` (последняя выбранная мелодия сохраняется в `SoundId`).

## 4. Логика (`Services/AlarmSchedule.cs`, чистый класс без MAUI)

- `DateTime ResolveNearest(TimeOnly time, DateTime now)` — сегодня в `time`, если это позже `now`, иначе завтра.
- `(int Days, int Hours, int Minutes)? Until(DateTime target, DateTime now)` — разница с округлением до минуты; `null`, если `target <= now`. Текст строит view model из ресурсов: есть дни → «N д H ч»; иначе «H ч M мин»; без часов → «M мин».
- `IReadOnlyList<CalendarCell> Month(int year, int month, DateOnly today, bool allowPast)` — ячейки с пустыми ведущими под понедельник; `CalendarCell(DateOnly? Date, bool IsPast, bool IsToday, bool IsWeekend, bool IsEnabled)`.

`AlarmEditViewModel` хранит сохраняемые значения (`Time`, `Date?`, `Repeat`, `Days`, `SoundEnabled`, `SoundId`, `VibrationEnabled`, `Label`) и черновики открытой шторки; при сохранении собирает `Alarm` как раньше (`Date == null` → `ResolveNearest`). `Alarm`, `AlarmService`, планировщики не меняются. Цифровые поля ЧЧ:ММ / ДД.ММ.ГГГГ, их обработчики и стили `DigitBox`/`DigitEntry` удаляются.

## 5. Остальные экраны

- **Список**: «Chrono» `appTitle` + кнопка-шестерёнка 42×42 (`Surface2`); строка «Ближайший — через …» `TextMuted`. Баннер надёжности — `Surface` с обводкой `Gold`, текст `GoldInk`. Карточка: `Surface`, обводка `Hairline`, радиус 20; время `listTime`; ниже «сб, 17 окт · Название · Пн Ср Пт» `TextMuted`; справа тумблер; выключенный — время `Hairline`. «+» — круг 60 `Metal` с кромкой `Gold`, тень primary.
- **Сигнал** (светлый): колокол в круге 180 `Metal` с кромкой `GoldEdge`, золотые волны; время `ringTime`, название 20/700, дата `TextMuted`; «Стоп» — primary во всю ширину. Пример: подпись, пример 40/800, ответы 2×2 secondary, «Неверно…» `GoldInk`.
- **Настройки**: шапка с назад (кнопка «OK» убирается). Группа «Умное пробуждение»: тумблер, описание, статус `GoldInk`, accent «Дать доступ», текст о приватности. Группа «Отключение сигнала»: `CheckBox` цвета `Text` «Решить пример» + описание. Строка «Надёжность ›».
- **Надёжность**: шапка с назад; пункты — строки в группе: кружок ✓ `Metal` или ! `Gold`, название, accent «Исправить»; подсказки `footnote`. Кнопка «OK» убирается.
- **Заставка**: фон `#F5F2EC`, колокол в круге `Metal` с кромкой, «Chrono» 28/800; анимация прежняя (качание, волны `Gold`). Нативный `MauiSplashScreen` — тот же колокол на `#F5F2EC`.
- **Иконка**: фон `#F5F2EC`, металлический круг с колоколом `OnMetal` и кромкой `Gold`. `bell.svg` перерисовывается в металл с золотом.
- **Уведомления** — системные, без изменений.

## 6. Проверка

- Эмулятор `chrono_api36` (`emulator-5570`, Android 16); пользовательский эмулятор не используется.
- После каждого блока: установка, запуск, скриншоты всех затронутых экранов и шторок.
- Барабан: `adb shell input swipe` по колонкам и нажатие на число; значение в полосе выбора совпадает с плашкой после «Окей».
- Календарь: листание, прошедшие дни не нажимаются, «Сегодня», «Очистить» → «Ближайшее».
- «Название»: ввод по одному символу с чтением поля после каждого, Backspace, скриншот с открытой клавиатурой («Сохранить» видна).
- Сохранение: `files/alarms.json` и `dumpsys alarm` совпадают с выбранным. Будильники — только на дальнюю дату, после проверки удаляются; экран сигнала открывается тестовым вызовом.
- `dotnet build Chrono.slnx` — 0 предупреждений; `dotnet test` — все тесты зелёные.

## 7. Тесты (одобрено пользователем)

`tests/Chrono.Tests/AlarmScheduleTests.cs` (файл `AlarmSchedule.cs` подключается в тестовый проект ссылкой, как остальные):
- `ResolveNearest`: время впереди → сегодня; прошло или равно → завтра; переход через конец месяца и года.
- `Until`: дни/часы/минуты, округление до минуты, `null` для прошлого и текущего момента.
- `Month`: смещение под понедельник (месяц с 1-м числом в понедельник и в воскресенье), число дней (30, 31, февраль 28/29), признаки прошлого, сегодня, выходных, `allowPast`.

## Вне объёма

Тёмная тема, переключение тем, изменение модели данных и планировщиков, iOS-специфичная полировка (сборка под iOS должна проходить), новые функции.
