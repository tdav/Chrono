> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Заменить заглушку «Цикл» вкладкой «Циферблат»: дела сегодняшнего дня секторами на 12-часовом циферблате, выбор сектора, «+».

**Architecture:**

- Данные: тот же `DayPlan.For`, что у «Распорядка». Новых хранилищ нет.

**Tech Stack:** .NET MAUI 11 (`11.0.0-rc.1.26451.6`, `net11.0-android;net11.0-ios`), CommunityToolkit.Mvvm, xUnit v3 (`tests/Chrono.Tests` подключает MAUI-независимые файлы через `<Compile Include … Link=…>`).

## Review Focus
1. **Дело через полдень (11:00–13:00):** видно в обеих половинах своими частями. Касание по любой из частей выбирает дело, в карточке полный интервал. Тест: задача 1, `Slices_CrossingNoon_ClippedIntoBothHalves`.
2. **Запись ровно в 12:00 или 00:00:** засечка попадает ровно в одну половину («Вечер» для 12:00, «Сейчас-утро» для 00:00), без дубля. Тест: задача 1, `Slices_TickAtNoon_OnlyInEvening`.
3. **Пустой день и касание пустого места:** ни ошибки, ни выбора. Тест: задача 1, `HitTest_EmptyArea_ReturnsNull`.
4. **«+» в 23:40:** редактор открывается на завтра 00:00, а не на прошедшее сегодня. Тест: задача 1, `FreeSlot_LateEvening_RollsToTomorrow`.
5. **Касание в центр и за обод:** выбора нет, центр — не сектор. Тест: задача 1, `HitTest_InsideHoleOrOutside_ReturnsNull`.

### Task 1: `DialLayout` — геометрия и правила циферблата

**Interfaces:**
- Consumes: `DayEntry(Alarm Alarm, DateTime Start, DateTime End, bool IsCurrent, bool IsDone, bool IsMuted)` из `Services/DayPlan.cs`; `Alarm.Id`, `Alarm.DurationMinutes`.
- Produces (namespace `Chrono.Services`):
  - `public enum DialHalf { Morning, Evening }` — Morning = [00:00, 12:00), Evening = [12:00, 24:00).
  - `public readonly record struct DialSlice(DayEntry Entry, double StartAngle, double SweepAngle, bool IsTick, int ColorIndex)`. Углы в градусах, 0 — «12 часов», по часовой стрелке, 30° на час. У засечки `SweepAngle = 0`.
  - `public static class DialLayout`:
    - `IReadOnlyList<string> Palette` — 12 цветов из Global Constraints.
    - `int ColorIndex(Guid id)`
    - `DialHalf HalfOf(DateTime moment)`
    - `IReadOnlyList<DialSlice> Slices(IReadOnlyList<DayEntry> entries, DateOnly day, DialHalf half)` — порядок отрисовки: сначала длинные, последними короткие и засечки (они сверху).
    - `double AngleOf(TimeOnly time)` — `(time.Hour % 12 + time.Minute / 60.0) * 30`.
    - `DayEntry? HitTest(IReadOnlyList<DialSlice> slices, double angle, double radiusFraction)` — `radiusFraction` = расстояние от центра / радиус обода. Кольцо секторов — `[0.52, 1.0]`, иначе `null`. Сектор: угол внутри `[StartAngle, StartAngle + SweepAngle)` с учётом перехода через 360° (сектор 270°+105° накрывает и 0°…15°). Засечка: попадание в ±4°. Из нескольких выбирается самый короткий (засечка короче любого сектора).
    - `DayEntry? Current(IReadOnlyList<DayEntry> entries, DateTime now)` — среди `DurationMinutes > 0 && Start <= now < End` самое короткое.
    - `DayEntry? Next(IReadOnlyList<DayEntry> entries, DateTime now)` — первое с `Start > now`.
    - `DateTime FreeSlot(IReadOnlyList<DayEntry> entries, DateTime now)` — по спецификации §6.7.
    - `const int DefaultNewMinutes = 30`.

Правила `Slices` (спецификация §6.3):
- Окно половины: `[day 00:00, day 12:00)` или `[day 12:00, day+1 00:00)`.
- Сектор (`DurationMinutes > 0`) обрезается окном: `StartAngle = AngleOf(max(Start, windowStart))`, `SweepAngle` — длительность пересечения в часах × 30. Пустое пересечение — среза нет.
- Засечка (`DurationMinutes == 0`) — только если `Start` внутри окна (полуинтервал).
- `ColorIndex = ColorIndex(Entry.Alarm.Id)`.
- `ColorIndex(id)`: байты `id.ToByteArray()`, сумма по модулю 12 (или иная детерминированная свёртка байтов) → `0..11`.
